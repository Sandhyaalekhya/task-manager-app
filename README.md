# Task Manager 📝

A comprehensive task management application designed to organize workflows, track deadlines, and improve daily productivity.

## 🚀 Core Features
- **Project Categorization:** Group tasks into different projects (e.g., Work, Personal, Shopping).
- **Priority Levels:** Assign importance levels (High, Medium, Low) to keep focused on critical items.
- **Due Date Tracking:** Visual indicators for upcoming or overdue deadlines.
- **Persistence:** All data is saved locally so your tasks remain after browser refreshes.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Storage:** Web LocalStorage API
- **Tooling:** Visual Studio Code, Git

## 🧠 Technical Implementation
- **Data Architecture:** Implemented a robust object-oriented structure to handle tasks as independent entities with associated metadata.
- **CRUD Operations:** Built fully functional Create, Read, Update, and Delete capabilities.
- **Dynamic DOM Manipulation:** Real-time UI updates that reflect state changes instantly without full-page reloads.
- **Filtering Logic:** Advanced array filtering to display tasks based on project category or priority status.
